Wrangle Report 🛠️

What's up with the data? 🤔

We got this big Twitter dataset full of dog ratings, tweet IDs, favorites, retweets, and even some pics. But like any raw data, it needed some cleaning up before we could use it.

Problems We Found 🚨

  1. Some tweets had more than one dog stage like "doggo pupper" — weird combo, right?
  2. There were retweets mixed with original tweets — we just want the real stuff.
  3. Missing values here and there like ratings without dogs or tweets without images.
  4. Data types were messy — some numbers were stored as text.

What We Did 💪

  • Dropped retweets. Only kept original tweets for clean insights.
  • Fixed rating numerator/denominator issues (some looked like fractions, others were just... off).
  • Created one column for dog stage instead of four (doggo, floofer, pupper, puppo).
  • Fixed data types: tweet IDs as string, ratings as float, etc.
  • Cleaned and merged extra info like image predictions and tweet metrics.

Result ✅

Boom! We ended up with a clean, organized DataFrame called twitter_archive_master — ready to dig into for insights 🔍
